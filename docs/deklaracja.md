Nazwa projektu: taskflow-aws

Opis projektu:

taskflow-aws to system webowy do zarządzania zadaniami, który porządkuje pracę w jednym, zawsze aktualnym miejscu.
Użytkownik po zalogowaniu może dodawać, przeglądać, edytować i usuwać swoje zadania oraz filtrować je według statusu i
priorytetu. Dostęp do funkcji aplikacji wymaga zalogowania.

Aplikacja wykorzystuje izolowaną strukturę trójwarstwową:

1. Warstwa Dostępu (Frontend): React
2. Warstwa Logiki (Backend API): Node.js + Express.js
3. Warstwa Danych (Database): PostgreSQL

Chmura: AWS

Front-end: React

Back-end: Node.js + Express.js

Baza danych:
PostgreSQL (Amazon RDS)
